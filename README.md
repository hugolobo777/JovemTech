# Jovem Tech — Algoritmos e Fundamentos em JavaScript

Repositório dedicado ao registro de aprendizado, desafios práticos e resolução de algoritmos desenvolvidos durante a capacitação do programa **Jovem Tech**. 

O objetivo deste diretório é consolidar os fundamentos da linguagem JavaScript, lógica de programação e resolução estruturada de problemas computacionais.

---

## 📌 Conteúdos Abordados

- **Lógica e Sintaxe Essencial**: Variáveis (`let`, `const`), tipos primitivos, operadores aritméticos e lógicos.
- **Estruturas de Controle**: Condicionais (`if/else`, `switch/case`) e laços de repetição (`for`, `while`, `for...of`).
- **Resolução de Algoritmos**: Exercícios de fixação, validações de dados e lógica aplicada a cenários reais.
